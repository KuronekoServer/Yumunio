# 編集の基本操作

Notionの[文章・ブロックの操作](https://www.notion.com/help/writing-and-editing-basics)と[キーボード操作](https://www.notion.com/help/keyboard-shortcuts)の目的を参考にした、Yumunioで現在使える操作です。AI機能は含みません。全機能・全ショートカットの互換を保証するものではなく、差分は[機能対応表](feature-coverage.md)で管理します。

| 操作 | 方法 |
| --- | --- |
| ブロックを追加 | 空行で `/`、またはブロック横の `+` |
| 見出し | 行頭で `#`・`##`・`###` とスペース |
| 箇条書き・チェックリスト | 行頭で `-`・`1.`・`[]` とスペース |
| 折りたたみ・引用 | 行頭で `>`・`"` とスペース |
| 太字・斜体・下線 | 文字を選択して Ctrl/⌘+B・I・U |
| インラインコード・取消線 | 文字を選択して Ctrl/⌘+E・Shift+S |
| 改行・次のブロック | Shift+Enter・Enter |
| 入れ子 | Tab・Shift+Tab。日本語変換中には実行しません |
| ブロックを選択 | 本文内で Esc。または「ページの編集オプション」から選択を開始 |
| 選択範囲を変更 | Shift+↑↓。チェックボックスのShiftクリックでも追加選択 |
| 全ブロックを選択 | ブロック選択中に Ctrl/⌘+A |
| コピー・切り取り・貼り付け | 選択後に Ctrl/⌘+C・X・V。コピー・切り取りは選択バーにも表示 |
| 複製 | Ctrl/⌘+D。選択中のブロック、または編集中のブロックを複製 |
| 削除・編集へ戻る | ブロック選択中に Delete/Backspace・Enter |
| 元に戻す・やり直す | 上部のボタン、または本文で Ctrl/⌘+Z・Shift+Z |
| ページを検索 | Ctrl/⌘+K。文字を選択中はリンクの編集を開きます |

タイトル・本文・データベースのプロパティは入力後に自動で反映されます。通常時は保存ボタンや保存状態を表示せず、そのまま編集を続けられます。ページ移動や詳細パネルを閉じる際も反映を待ちます。日本語の変換中は送信せず、通信待ちの間に書き足した内容も保持します。通信失敗・競合・不正な値がある場合は案内を表示します。未反映のままタブを閉じようとすると確認が出ます。オフライン保存や、端末を強制終了した場合の復元には対応していません。

ブロック単位でコピーすると、書式・入れ子・表・チェック状態を保持します。貼り付けるブロックのIDは自動生成します。複数行の通常テキストは段落として貼り付け、コード・数式の入力欄では改行を含む文字として扱います。切り取りはクリップボードへの書き込みが成功してから実行し、1回の「元に戻す」で内容を復元できます。

画像・ファイル・PDFは本文に貼り付けるかドロップできます。表計算ソフトのセル範囲は表として、表のセル内ではセル範囲として貼り付けます。添付を含むブロックも、同じアカウント・ワークスペース内で権限のある別ページへコピーできます。元ページの閲覧と貼り付け先の編集権限を確認し、添付に新しいページ専用のIDを作ります。

複数の段落にまたがる文字選択のコピーは、選択範囲の書式とブロック構造を保持します。部分選択の切り取りは従来の文字編集です。共同編集中も、表のセル・行・列の編集、添付の追加、ブロックのコピー・切り取り・貼り付けが使えます。新規に貼り付ける人物・ページ参照は共同編集の現在の制約により表示文字として保持し、案内を表示します。既存の参照や添付は保持します。カラム構成の新規作成など一部操作は共同編集を停止してから行います。

本文の標準幅、全幅、文字サイズ、アイコン、カバーはページの操作から変更できます。変更はNext.jsの画面と共有デザイン `Yumunio.pen` に反映しています。

本文の間にデータベースを置くには `/` →「データベースを挿入」を選びます。同じDBを複数の場所に置き、場所ごとに表示形式・フィルター・並び順・列を保存できます。行やカードは右側で開き、本文とプロパティを編集した後に一覧へ戻れます。詳しくは[本文内DBと詳細編集](inline-databases.md)を参照してください。

「DBテンプレート」で本文のひな形と初期値を登録できます。[テンプレートと自動項目](database-templates.md)、共通の注意書きを複数ページに置く[同期ブロック](synced-blocks.md)も利用できます。
