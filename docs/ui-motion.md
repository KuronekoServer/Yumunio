# 画面の動きと実装方針

Motion for Reactを使用し、短い動きで操作の結果と画面のつながりを示します。
数値はYumunioの調整値です。

| 対象 | 時間 | 動き |
| --- | --- | --- |
| 右側の詳細パネル | 200ms | 右端から移動。保存の確認後に閉じる |
| サイドバーのメニュー、ページ・ブロックの操作メニュー | 120ms | フェードと4〜6pxの移動 |
| サイドバー | 200ms | 本文の幅とサイドバーの位置を一緒に変更 |
| ワークスペースのモーダル | 160ms | フェードと小さな移動。背景の暗転も同じ時間 |
| 本文内のドラッグ配置後 | 160ms | 位置が変わったブロックを配置先へ移動 |

いずれも強いバウンドのないtweenです。OSの「動きを減らす」が有効なら、移動とアニメーションの待ち時間を省きます。
設定は表示中の変更にも追従します。スクロールや次の入力を待たせるグローバルな操作ロックは設けません。
保存が必要な詳細パネルでは、既存の保存確認が済んでから閉じます。

## 編集とキーボード操作

Reactが管理する詳細パネルの外枠、サイドバー、メニュー、モーダルに適用しています。
詳細内のエディターは同じiframeを保持し、保存状態の表示更新で作り直しません。
本文のDOM、文字選択、YjsのデータやUndo／Redoをアニメーション用に再構築しません。

メニューはEscで閉じて開いたボタンへ戻れます。サイドバーメニューは↑↓・Home・Endで項目を移動できます。
モーダルは標準のdialogのフォーカス制御を使い、閉じ終わってから元の操作位置へ戻します。
日本語変換中のEscで詳細やメニューを閉じません。既存の未保存・処理中の閉じる制約も維持します。

ドラッグ開始・移動先の表示・キーボード操作は既存のdnd-kitが担当します。
Motionのdragは使用せず、配置後の位置変化だけを補間します。
次のドラッグを始めると、前の配置アニメーションを解除します。

依存パッケージは`apps/web/package.json`、共通の時間とイージングは`apps/web/public/ui-motion-policy.js`、
Reactの実装は`apps/web/src/motion/`の部品に分け、`apps/web/src/ui-motion.jsx`から公開します。
パネルの保存確認は`apps/web/public/record-panel.js`、標準dialogとの接続は`apps/web/public/motion-dialog-controller.js`に分離しています。
設定画面など、ワークスペース外のモーダルは適用範囲に含みません。
デザインの動きと状態は共有ファイル`Yumunio.pen`にも記録します。

## 確認する操作

1. 課題一覧のスクロール位置とフィルターを決め、行を右側で開く。
2. 本文とプロパティを編集し、入力直後に閉じる。保存後に閉じることを確認する。
3. 一覧の位置・選択・表示設定とフォーカスを確認し、もう一度開いて保存された内容を確認する。
4. メニューをキーボードで開閉し、モーダルやサイドバーの連続操作を確認する。
5. 日本語変換、文字選択、Undo／Redo、共同編集、ドラッグ配置を確認する。
6. OSの「動きを減らす」を有効にして同じ操作を確認する。

公式資料: [インストール](https://motion.dev/docs/react-installation)、[useReducedMotion](https://motion.dev/docs/react-use-reduced-motion)。
