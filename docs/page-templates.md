# 新しいページのテンプレート

サイドバーの「ページを作成」から、白紙またはひな形を選んでページを作成できます。
ページの「下にページを追加」とチームスペース内の追加ボタンにも、同じ選択画面が開きます。

1. 追加先を確認します。自分用のプライベートページ、作成権限のあるチームスペース、管理できる親ページを選べます。
2. テンプレートを選び、本文のプレビューを確認します。名前や説明から検索できます。
3. ページタイトルを必要に応じて変え、「この内容で作成」を押します。

作成前に閉じた場合、ページは増えません。作成後は普通のページとして本文・チェックリストを編集できます。
タイトルを手入力した後は、別のテンプレートを選んでもそのタイトルを保持します。

| テンプレート | 最初に入る内容 |
| --- | --- |
| 白紙のページ | 空の段落 |
| 議事録 | 日時・参加者、議題、話したこと、決定事項、次のアクション |
| プロジェクト計画 | 目的、範囲、マイルストーン、タスク、懸念、参考情報 |
| 課題報告 | 概要、環境、再現手順、期待・実際の動作、完了条件 |
| タスクチェックリスト | 今日と次にやること、メモ |
| 手順書 | 目的、事前準備、番号付き手順、対処方法、関連情報 |
| 週次レビュー | 目標、進捗、気づき、困っていること、来週のアクション |

用意されたひな形はサーバーの追加設定なしで使えます。画面の表示言語に合わせて日本語または英語の本文を作成します。
作成済みの本文は、表示言語やひな形を後で変更しても書き換わりません。

「個人テンプレートを管理」では、自分が使うページをひな形として保存できます。
保存した個人テンプレートも、新規ページ画面に名前で表示され、選ぶと内容を読み込みます。
この一覧はログイン中のアカウントとワークスペースに限定されます。
個人テンプレートには、保存時に確認した本文だけが入ります。添付、子ページ、DB、共有権限などは引き継ぎません。

どのテンプレートも独立したコピーです。元のひな形や別のコピーを編集しても相互に影響しません。
追加先の親ページ・チームスペースの共有設定は新しいページにも適用されるため、作成前に追加先の説明を確認してください。

DBの新規行に本文とプロパティの初期値をまとめて適用する場合は、[DBテンプレート](database-templates.md)を使ってください。
本文にDBを配置する方法は[本文内DBと詳細編集](inline-databases.md)を参照してください。

## テンプレートの追加と翻訳

用意されたひな形の構成は `apps/web/public/page-starters.js`、名前・説明・本文は
`apps/web/public/workspace-locales/{ja,en}.json` の `pageTemplates.*` にあります。
IDや利用者の情報を埋め込まず、通常のテキストブロックとチェックリストで定義します。
翻訳の追加・修正は[コミュニティ翻訳](community-translations.md)と同じGitHubの手順です。
`node --test apps/web/test/page-starters.test.js apps/web/test/page-creator.test.js` と `npm run check` で構成・言語間の対応を検証できます。
