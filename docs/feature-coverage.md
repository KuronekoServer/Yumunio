# Notionから移行するための機能対応表

確認日: 2026-10-20。AI生成・AIエージェントは利用者の指定により対象外です。
Notionと同じ作業を行えることを目標に、独自の実装・表示・文言で段階的に対応します。
「実装済み」はローカルのコードとテストの確認を指し、公開・本番反映とは区別します。

| 段階 | 機能 | 現在の状態・残る差分 |
| --- | --- | --- |
| 1 編集 | 文章、見出し、箇条書き、タスク、引用、区切り、コード | 実装済み |
| 1 編集 | 太字、斜体、取消線、下線、コード、リンク | 実装済み。HTMLの見出し・太字・リスト・リンクの貼り付けにも対応 |
| 1 編集 | 折りたたみ、コールアウト、目次、パンくず、ブックマーク、数式 | 実装済み。数式はアプリ内で描画。生成ブロックは共同編集中は閲覧のみ |
| 1 編集 | カラム、ネスト、移動、Undo/Redo、自動保存 | 実装済み |
| 1 編集 | ブロック複製、ブロックへのリンク | 実装済み。同一ページ内の添付参照を保持 |
| 1 編集 | 複数ブロックのコピー・カット・貼り付け | ブロック単位の選択に対応。書式・入れ子・表を保持し、新しいIDを自動生成。添付を含むコピーは同じページ内のみ。段落をまたぐ部分的な文字選択の構造保持は未対応 |
| 1 編集 | キーボード操作 | Escでブロック選択、Shift+矢印で範囲変更、Ctrl/⌘+C/X/V/D、選択後の全選択・削除・Enterで編集に対応。インラインコードと取消線のショートカット、`>`で折りたたみ・`"`で引用にも対応。Notionの全ショートカットには未達 |
| 1 編集 | 画像・ファイルの貼り付け、表・セル範囲の貼り付け | 実装済み。共同編集中の構造変更には制約あり |
| 1 編集 | PDFの本文表示、音声・動画の再生 | 実装済み。形式確認・閲覧権限の再確認・部分取得に対応。ブラウザーが再生できる形式に限る |

| 2 ページ管理 | Wiki、ページの担当者・検証・有効期限 | 未対応 |
| 3 データベース | Table/Board/List/Gallery/Calendar/Timeline/Chart/Feed | 実装済み |
| 3 データベース | 型付きプロパティ、Relation、Formula、Rollup、フィルター・ソート | 実装済み。Notionの全関数・全設定との互換性は未達 |
| 3 データベース | URL・メール・電話・ステータス・ファイル・ID・作成/編集情報 | 標準の型以外は未対応 |

| 3 データベース | インライン/リンク済みDB、サブアイテム、依存関係 | 未対応 |

| 4 共有・運用 | Webhook | ページ更新・タイトル/本文更新・作成・移動・ごみ箱・復元の7イベント。署名、永続キュー、再送、購読停止/再開、配送状況に対応。通知はメタデータのみ。送信先は運営者が設定する1か所 |
| 4 共有・運用 | 閲覧オフライン・復帰時の同期、Webクリッパー | ブラウザー内ノート/PWAは実装済み。共有ページのオフライン同期は未対応 |
| 4 共有・運用 | SAML/SCIM、監査ログ、詳細な組織ポリシー | 一部管理機能あり。Enterprise機能全体は未達 |

追加した機能は共通モデルとAPIで保存・権限を確認しています。折りたたみとコールアウトの本文は公開ページ・テンプレートにも対応します。目次・パンくず・ブックマーク・数式や添付は公開スナップショットに含めません。

画面はNext.js 16のApp Routerへ移行しています。セットアップと編集画面のナビゲーション・操作バーをReactで実装し、既存のブロック編集や管理ウィジェットは専用領域へ接続します。Node.jsとWorkersは同じ静的出力を配信します。詳細は[画面構成](frontend-architecture.md)を参照してください。

基本操作は[編集操作の案内](editing-basics.md)、外部から接続できる範囲と設定は[API・MCP・Webhook](integrations.md)に記載しています。残る通常機能は上表の編集・ページ管理・DB・共有の各段階で引き続き管理します。未対応の行を実装済みとして扱いません。
