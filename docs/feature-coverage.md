# Notionから移行するための機能対応表

確認日: 2026-10-20。AI生成・AIエージェントは対象外です。
Notionと同じ作業を行えることを目標に、独自の実装・表示・文言で段階的に対応します。
「実装済み」はローカルのコードとテストの確認を指し、公開・本番反映とは区別します。

| 段階 | 機能 | 現在の状態・残る差分 |
| --- | --- | --- |
| 1 編集 | 文章、見出し、箇条書き、タスク、引用、区切り、コード | 実装済み |
| 1 編集 | 太字、斜体、取消線、下線、コード、リンク | 実装済み。HTMLの見出し・太字・リスト・リンクの貼り付けにも対応 |
| 1 編集 | 折りたたみ、コールアウト、目次、パンくず、ブックマーク、数式 | 実装済み。数式はアプリ内で描画。生成ブロックは共同編集中は閲覧のみ |
| 1 編集 | カラム、ネスト、移動、Undo/Redo、自動保存 | 実装済み |
| 1 編集 | ブロック複製、ブロックへのリンク | 実装済み。同一ページ内の添付参照を保持 |
| 1 編集 | 複数ブロックのコピー・カット・貼り付け | 書式・入れ子・表・添付の保持と、権限のある別ページへのコピーに対応。複数段落にまたがる部分的な文字選択のコピーにも対応 |

追加した機能は共通モデルとAPIで保存・権限を確認しています。折りたたみとコールアウトの本文は公開ページ・テンプレートにも対応します。目次・パンくず・ブックマーク・数式や添付は公開スナップショットに含めません。

画面はNext.js 16のApp Routerへ移行しています。セットアップと編集画面のナビゲーション・操作バーをReactで実装し、既存のブロック編集や管理ウィジェットは専用領域へ接続します。Node.jsとWorkersは同じ静的出力を配信します。詳細は[画面構成](frontend-architecture.md)を参照してください。

基本操作は[編集操作の案内](editing-basics.md)、外部から接続できる範囲と設定は[API・MCP・Webhook](integrations.md)に記載しています。残る通常機能は上表の編集・ページ管理・DB・共有の各段階で引き続き管理します。未対応の行を実装済みとして扱いません。
