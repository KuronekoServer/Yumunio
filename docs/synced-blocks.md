# 同期ブロック

空行の `/` または `+` →「同期ブロックを挿入」から、共通の本文を複数ページに置けます。
新しい原本ページを作るか、閲覧できる既存ページの本文を選びます。
配置には「同期されている内容」と表示し、通常のコピーと区別します。
原本には専用のページがあり、配置先に保存するのは原本ページのIDだけです。

「同期した内容を編集」を選ぶと、配置先を残して右側に通常のエディターが開きます。
編集可能な同期元ではYjs共同編集を自動で開始します。本文・表・添付などは通常の共同編集と同じです。
閉じる操作は未保存の変更の同期を待ちます。「全画面で開く」から原本を通常ページとして開けます。
同じブラウザーには保存通知を送り、ほかのブラウザーの表示も約5秒間隔で更新します。
入れ子の同期参照とDBは、原本へのリンクとして表示します。再帰的な自動展開は行いません。

| 操作 | この配置 | 同期元とほかの配置 |
| --- | --- | --- |
| 原本を編集 | 更新する | すべて更新する |
| 通常のコピーに戻す | 現在の本文を独立したブロックへ変換 | 変更しない |
| この配置を削除 | 参照を削除 | 内容と配置を残す |
| 原本ページをゴミ箱へ | 表示できない旨を示す | すべての同期表示が利用不可。復元すると再び利用可能 |

解除時に画像・ファイルがあれば、原本の閲覧と配置先の編集権限を確認してページ専用の添付参照を作ります。
独立したコピー以降の変更は原本に反映しません。通常のUndo/Redoで配置の解除や削除を取り消せます。

配置先を共有しても原本の共有範囲は広がりません。原本の本文と添付は常に原本のAPIで権限を確認します。
原本を閲覧できない人には内容を表示せず、編集には原本の本文編集権限が別途必要です。
アクセスを失った場合は表示内容を消し、対応する詳細パネルを閉じます。
公開ページの静的スナップショットでは原本の内容を展開しません。
