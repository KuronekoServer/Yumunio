# ブロックのサイズとレイアウト

文章・案内・画像・本文内データベースを横に並べ、内容に合わせて幅を変えられます。保存した比率は、ページを開き直した後も保持します。

## 横に並べる

ブロックのハンドルを別のブロックの左端・右端へドラッグします。縦のガイドが表示された位置へ置くと、2列になります。複数ブロックの選択もまとめて配置できます。本文や添付を複製する操作ではないため、ブロックのIDやDBの参照先は保持します。

ドラッグを使わない場合は、ブロックのメニューから「このページ内で移動」を開き、対象と「左に並べる」「右に並べる」を選びます。既存の2列・3列の挿入、列へのブロック移動、1列へ戻す操作も利用できます。カラムの中にさらにカラムを作る配置は現在対象外です。

## 列幅を変える

列の間にポインターを合わせ、境界をドラッグします。3列では、境界の両隣だけを変更します。ドラッグ中はプレビューし、離した時点で保存対象にします。Esc、画面の切り替え、ウィンドウからのフォーカス移動で取り消します。

境界にキーボードでフォーカスすると、次の操作が使えます。

| 操作 | 結果 |
| --- | --- |
| ← / → | 1%ずつ変更 |
| Shift + ← / → | 5%ずつ変更 |
| Home / End | 隣の列が残る範囲で最小・最大に変更 |
| Enter / ダブルクリック | すべての列を均等に戻す |

カラム全体のメニューでは、各列の幅を数値で指定できます。各列15%以上、合計100%にします。2列・3列への構成変更でも、既存の内容と幅の比率を引き継ぎます。横幅を広く使う場合は「ページの操作」→「ページの表示」で全幅を選びます。

## 添付とデータベース

画像・PDF・動画は端のハンドル、またはブロックの「添付のサイズと配置」で、表示幅と左右・中央の配置を変更できます。元のファイルは変更しません。

本文内DBの「…」→「タイトルとレイアウトを編集」では、この場所のタイトル・絵文字・タイトル表示の有無・一覧の最大の高さを指定します。高さは200〜1200pxで、それを超える一覧は内部でスクロールします。幅の調整中も、左右の一覧、選択した行、スクロール位置はそのままです。「表示設定」で指定したビュー・フィルター・並び順・表示列も保持します。

DBの内容は引き続き参照元の権限で読み込みます。表示名やレイアウトの変更によって、閲覧権限や共有範囲は変わりません。参照元の閲覧権限が失われると一覧を消去します。

## 共同編集と狭い画面

共同編集中も、列幅、左右への配置、添付の表示サイズ、DBのタイトルと高さを変更できます。Yjsで変更を共有し、1回のドラッグを1回のUndoとして扱います。他の人の本文編集を巻き戻しません。空のカラムの挿入、列数の変更・解除も共同編集のまま行えます。

ドラッグ中に別のレイアウト変更・権限変更・ページ移動が発生すると、そのプレビューを取り消します。本文エディターのDOMは、幅のプレビューや確定のために再生成しません。日本語変換中は構造変更を開始しません。

狭い画面では列を縦に並べ、画像は表示領域に対する幅の比率を保ちます。保存した列幅は変更せず、広い画面へ戻ると元の比率になります。OSの「動きを減らす」設定を尊重します。
