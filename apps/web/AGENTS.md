# Design changes

- Use `Yumunio.pen` at the repository root as the shared design document. When changing layouts, colors, spacing, typography or components, update the corresponding Pen screens and reusable components in the same task as the implementation.
- Read and edit `.pen` files only through the Pencil MCP tools. Preserve existing screens and user edits; add the relevant states and verify the changed screens with screenshots.
- Use the user's Notion references for document hierarchy, navigation density and readability. Use original Yumunio content, icons and assets.
- Keep the browser and server theme palettes, the canonical theme fixture and Pen theme variables consistent. Preserve a user's saved theme choice.
- Verify the affected Next.js pages in a browser and run checks appropriate to the change. Distinguish design screenshots, browser checks and deployment evidence.
